## 🌟 Featured Projects

### [🎯 AI Meeting Assistant](https://github.com/Vanoushika/ai-meeting-assistant)
Full-stack AI application that automates meeting documentation, reducing post-meeting admin time by 90%.

**Tech Stack:** Python, FastAPI, React, Vite, Groq API (Whisper + Llama 3.3), Resend  
**Live Demo:** [ai-meeting-assistant-tan.vercel.app](https://ai-meeting-assistant-tan.vercel.app)

**Key Features:**
- 🎙️ Audio transcription using Whisper Large V3 Turbo
- 🤖 AI-powered summaries with Llama 3.3 70B
- 📧 Automated email delivery with professional HTML templates
- ⚡ Full-stack deployment (Render + Vercel)

**Impact:** Processes 1-hour recordings in under 60 seconds, generates actionable summaries with key points and action items.
